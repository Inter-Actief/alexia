{% trans 'Login' %}

{% blocktrans trimmed %} Logging in to Alexia is done using your UTwente account (s- or m-number and the corresponding password). The password for the old drinks management system is therefore no longer used. {% endblocktrans %}

{% blocktrans trimmed %} On the login page you can also indicate which organization you are logging in for, by clicking the logo of that organization. {% endblocktrans %}

{% trans 'Logging in for the first time' %}

{% blocktrans trimmed %} If you log in for the first time, you may be asked for your name and/or email address. Here you fill in the email address on which you want to receive all emails from Alexia. {% endblocktrans %}

{% trans 'Indicate availability' %}

{% blocktrans trimmed with event_list_url=event_list_url %} If you are a bartender for an organization, you can indicate your availability under the Planning button. On this page you can see all scheduled events. For events where your organization participates, you can use the dropdown menu on the right to indicate whether you want to tend that event. {% endblocktrans %}

{% blocktrans trimmed with profile_url=profile_url %} Can't change your availability? Check whether you have selected the correct organization in the top right of the page. Under My profile (section Authorization) you can check whether you are also registered as a bartender with your organization. It may also be that indicating availability has been disabled for an event. {% endblocktrans %}

{% trans 'Schedule events' %}

{% blocktrans trimmed with new_event_url=new_event_url event_list_url=event_list_url %} With the Add event button on the Planning page, you can schedule new events as a Planner. With the pencil icon you can modify events, and with the trash icon you can delete scheduled events. {% endblocktrans %}
